Problem: "Access token not configured"
Solution: 
  □ Check .env file has META_CAPI_ACCESS_TOKEN
  □ No spaces around the = sign
  □ Restart server after adding

Problem: Events not showing in Meta
Solution:
  □ Wait 1-2 minutes (can have delay)
  □ Check server logs for errors
  □ Verify Pixel ID matches (1230498898985591)
  □ Check access token is valid

Problem: "Failed to send event" in logs
Solution:
  □ Check internet connection
  □ Verify access token hasn't expired
  □ Check Meta Events Manager for error details
  □ Try generating new access token

Problem: Low Event Match Quality (<50%)
Solution:
  □ Ensure customer email/phone are captured
  □ Phone numbers need +92 country code
  □ Include fbp and fbc cookies in requests
  □ Wait for more data (needs 100+ events)
